SDF JAVA PROJECT


Objective

  • Implementation of an infinite/arbitrary-precision arithmetic library in Java using OOP concepts.
  • If you are given two strings as input, you need to add support for addition, subtraction, multiplication and division, for both integer and float data types.

library Specification

It has a package called arbitraryarithmetic which consists of two classes AInteger and AFloat.

Deeper into the methods

add(AInteger other)

  • First, I removed any leading zeros from the inputs using a dedicated function.
  • This function adds any two integers, whether positive or negative.
  • I initially ensured it worked correctly for positive integers.
  • I implemented the addition using a digit-wise approach, similar to the traditional method taught in basic arithmetic.
  • The numbers are processed in a while loop, where each digit is added starting from the unit's place.
  • Within each iteration of the loop, the carry value is updated accordingly.
  • Once the loop completes, any remaining carry is added to the final sum.
  • For negative integers, if both numbers are negative, I simply add their magnitudes and prefix the result with a minus sign.
  • If one number is negative and the other is positive, I pass them as inputs to the subtraction method.
  • Finally, I passed the result to a function that removes any leading zeros.

sub(AInteger other)

  • First, I removed any leading zeros from the inputs using a dedicated function.
  • As with addition, I initially implemented subtraction for positive integers.
  • I compared the inputs to determine whether the result should be positive or negative.
  • The subtraction was performed by subtracting the smaller number from the larger one.
  • I used a digit-wise subtraction approach, following the basic method.
  • In each iteration of the loop, I subtracted the corresponding digits and updated the borrow as needed.
  • Depending on the earlier comparison, I prefixed the result with a minus sign if necessary.
  • If both inputs were negative, I simply reversed the order of the operands before performing the subtraction.
  • If one input was positive and the other negative, I passed them to the addition method instead.
  • Finally, I passed the result to a function that removes any leading zeros.

mul(AInteger other)

  • First, I removed any leading zeros from the inputs using the dedicated utility function.
  • I initially implemented multiplication for positive integers, building upon the logic used for addition and subtraction.
  • I decomposed the first input into its place-value components, e.g., 213 was represented as 2×100 + 1×10 + 3×1.
  • Each digit of the first number was multiplied with the second number using repeated addition, appending the appropriate number of trailing zeros based on the digit's position, and then all partial results were summed.
  • If both input numbers were negative, I multiplied their absolute values.
  • If only one of the inputs was negative, I multiplied their absolute values and prefixed the result with a minus sign.
  • Finally, the result was passed through a function to remove any leading zeros before returning it.

div(AInteger other)

  • As with other arithmetic operations, I first removed any leading zeros from the inputs.
  • I checked if the divisor was zero and, if so, threw an error to handle division by zero.
  • If the dividend was zero, I immediately returned zero as the result.
  • I then implemented the long division algorithm for performing the division.
  • The quotient was calculated by iterating through the digits of the dividend.
  • If both input numbers were negative, I divided their absolute values.
  • If only one of the inputs was negative, I divided their absolute values and prefixed the result with a minus sign.
  • Finally, the result was passed through a function to remove any leading zeros before returning it.

A deeper look into methods

add(AFloat other)

  • I implemented the add() method in AFloat.java to perform addition of two floating-point numbers represented as strings.
  • First, I extracted both numbers as strings and determined the number of digits after the decimal point for each.
  • If a number didn't already contain a decimal point, I appended one to ensure consistent processing.
  • If both operands had the same number of digits after the decimal, I removed the decimal points and treated them as integers, performed the addition using the AInteger class, and then reinserted the decimal point at the correct position based on the decimal length.
  • If the decimal lengths were unequal, I padded the operand with fewer decimal digits with extra zeroes to the right until both had equal lengths. Then, I performed the same integer-based addition and reinserted the decimal point appropriately.
  • I handled both positive and negative results, carefully adjusting the position of the decimal point while ignoring the negative sign during calculations and reinserting it afterward.
  • If the result’s length was less than the expected number of decimal digits, I prefixed the result with necessary zeroes to maintain decimal accuracy.
  • After constructing the result string, I removed any unnecessary leading zeroes and used the remove_extra_zeroes() and truncate() functions to clean up the result before returning it.

sub(AFloat other)

  • Convert both operands to strings and ensure they have a decimal point.
  • Equalize the number of decimal digits by padding the shorter one with trailing zeroes.
  • Remove decimal points and convert the resulting strings to AInteger objects.
  • Perform integer subtraction using AInteger.sub().
  • Re-insert the decimal point into the result based on the maximum decimal length.
  • Format the result properly: handle negative values, leading/trailing zeroes, and truncation.
  • Return the final result as a new AFloat object.

mul(AFloat other)

  • Convert both operands to strings and ensure they contain a decimal point.
  • Remove the decimal points and convert to pure integer strings.
  • Trim leading zeroes from both integer strings.
  • Convert them to AInteger objects and multiply using temp1.mul(temp2).
  • Insert the decimal point in the result based on total decimal digits from both operands.
  • Format the final result: manage sign, leading/trailing zeroes, and decimal precision.
  • Return the final result as an AFloat after trimming and truncating.

div(AFloat other)

  • Add .0 if either operand lacks a decimal.
  • Remove decimal points to treat numbers as integers.
  • Trim leading zeros; preserve sign.
  • Throw error if divisor is zero; return zero if dividend is zero.
  • Perform integer division to get quotient and remainder.
  • Adjust quotient sign based on input signs.
  • Use remainder to generate decimal part via long division (30 digits max).
  • Adjust decimal point based on difference in original decimal lengths.
  • Remove unnecessary leading zeros in result.
  • Return result after checking for exact match with original dividend.

build.xml

  • Defines a project named "Arbitrary Arithmetic Operations" with default target jar.
  • Sets both source and build directories to the current folder, so .class files go alongside .java files.
  • compile target compiles arbitraryarithmetic/*.java into the same directory.
  • jar target creates aarithmetic.jar containing all .class files from the current directory tree.
  • clean target deletes the .jar file and all .class files from the directory.
